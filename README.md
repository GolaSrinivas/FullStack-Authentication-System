# Full-Stack Authentication System

A full-stack authentication application built with Next.js, TypeScript, and MongoDB, featuring secure user authentication and email integration.

## Tech Stack
- Next.js
- TypeScript
- MongoDB
- Mailtrap

## Features
- User Signup and Login
- Email Verification
- Forgot and Reset Password
- Password Hashing
- Responsive UI

## Getting Started

```bash
npm install
npm run dev
```

Configure the required environment variables in `.env.local` before running the application.
